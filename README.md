# Campus Lost & Found Management System

## Abstract

The Campus Lost & Found Management System is a Flutter-based mobile application that helps students and staff report, search, and recover lost items within a college campus. It provides a centralized and user-friendly platform to manage lost and found items efficiently.

## Problem Statement

Finding lost belongings on campus can be difficult because information is often shared through informal methods. This project aims to organize lost and found reports in one accessible platform.

## Objectives

- To provide a digital platform for reporting lost and found items.
- To make searching for misplaced belongings easier.
- To organize item details in a centralized system.
- To improve the item recovery process.

## Key Features

- Report lost items
- Report found items
- Search and browse items
- View item descriptions and locations
- Manage reported items

## Technologies Used

- Flutter
- Dart
- Git and GitHub

## Future Enhancements

- Firebase database integration
- User authentication
- Item image uploads
- Notifications for possible matches

## Expected Outcome

The application aims to make lost and found item management easier, faster, and more organized within a college campus.

## Conclusion

This project provides a simple digital solution to help students and staff report and recover misplaced belongings.
